D768 的后期帧改善尤其明显；其 10k F1 0.2392 已接近 D512 20k F1 0.2433。同时，D768 10k 的 active MSE 从 D512 的 0.01470 降至 0.01310，但整幅 voxel MSE 从 0.000321 升至 0.000344，再次说明整幅 MSE 不适合作为这里的主指标。
两次评估的窗口、种子、归一化和采样设置一致，训练学习率也都按 40k 曲线运行。不过 D512 使用 RTX 6000 Ada 且开启 compile，D768 使用 L40 且关闭 compile；训练样本顺序也未证明完全相同。因此结果支持“这次 D768 运行明显更好”，尚不能把全部增益严格归因于 dim。
