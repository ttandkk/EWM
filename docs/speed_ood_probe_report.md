# Speed OOD Probe 全实验汇总与分析报告

整理日期：2026-10-11（Asia/Shanghai）。本报告仅汇总已有结果，没有启动新训练或测评。覆盖11组完整OOD probe（25个方法/配置行、75个种子运行记录）及194739训练诊断。相同对照复测也保留，不能将它们当作独立新增数据集。

## 1. 结论

- 在这组固定测试集上，**三档OOD宏平均最好的配置是静态EWM patch4投影＋预测头**（0.003187 m/s）；随机投影0.003207、动态投影0.003249，数值接近，未做显著性检验，不能据此断言静态预训练更好。
- **最高速0.09 m/s上最好的配置是连续10-bin像素差分CNN**：MAE 0.003700 m/s，平均预测0.088270 m/s。它在低速0.03上不如RGB历史和patch读出，因此不是所有OOD速度上的统一最优。
- 同容量10-bin对照中，像素差分较特征差分将OOD宏平均MAE由0.007522降至0.004665（约38.0%）；差分位置有明确实测价值。
- 原始稀疏memory与独立时间token均没有超过CNN。取消早停修复了部分ID拟合问题，但没有修复OOD外推；扩大D128到D768也未带来稳定收益。
- **可从历史latent/patch投影读出速度，不等于原EWM已利用速度完成未来外推。** Probe额外使用10-bin历史并在均匀速度上有监督训练；动态源EWM182549则在固定0.06 m/s训练，且生产路径仅输入当前bin。

## 2. 数据、指标与比较边界

- 标签：传送带设定速度（m/s），不是接触后物体瞬时速度，也不是动作或成功率。训练来源为均匀0.04–0.08 m/s的50条示范；按episode分40训练/10验证，共667/167个窗口。
- 配对测试：10个场景种子20291000–20291009 × 6档速度，共60条序列。0.04、0.06、0.08属于训练范围内新场景速度对照；0.03、0.085、0.09为OOD。不同速度复用初始场景，采用共同的接近物体前窗口；接近筛选是TCP距离阈值代理，不是精确接触标记。
- 所有正式probe用训练种子42/43/44；只依据ID验证集选checkpoint，不依据OOD选权重。AdamW lr=3e-4、wd=1e-4、batch64、clip1、BF16；早停差异见实验表。诊断中的FP32/lr变化单列。
- 所有输入为双摄像头128×128。4帧/bin时间点为[-9,-6,-3,0]/30秒；连续10-bin为[-9,…,0]/30秒，首尾跨度均0.3秒。连续event积累支持约0.333秒；单event bin本身已有约33.3ms运动信息，不能等同于瞬时RGB。
- Event保留OFF/ON，原count clip15后2×2面积汇总，packed通道按[60,120,60]归一化。像素差分保留当前帧锚点并做有符号相邻差分，不取绝对值、不截断。
- MAE采用每条episode内窗口MAE再等权平均。下表先对3个训练种子求均值；OOD宏平均=(MAE@0.03+MAE@0.085+MAE@0.09)/3。±为3个种子的总体标准差（ddof=0），不是置信区间；宏平均标准差先逐种子宏平均再计算。
- ID验证MAE与测试集中的0.04/0.06/0.08 MAE不是同一指标。预测均值接近真值也不保证逐窗口误差小。三档OOD宏平均有两档高速，不是低/高速各50%加权。
- 原始CNN从头训练；VAE为冻结预训练编码器。不同家族的先验、参数量和头部空间组织不同，因此跨家族排名为描述性比较；因果结论优先使用同一job的匹配对照。

## 9. 各实验链条的解释

### 9.1 RGB与event历史

RGB单帧到4帧历史显著改善ID和OOD；event从单bin到历史也改善，但最初的4-bin特征差分CNN落后于RGB4。不能据此断言event先天信息不足：两者预处理、编码归纳偏置及事件累积的时间信息不同。194643使用同一个10槽位网络，比较重复填充的4个实际bin与连续10个bin，补齐中间观测改善OOD，但仍未达到后来的像素差分性能。
### 9.2 差分位置

4-bin像素输入为[E3,E1-E0,E2-E1,E3-E2]；10-bin为[E9,E1-E0,…,E9-E8]。保留锚点使变换在精确算术中可逆，收益更符合输入表征与学习偏置的改变，而非新增信息。feature_diff则先逐帧CNN，再用当前特征和相邻特征差分。194851/194865各自内部容量匹配；跨4/10-bin参数从286,881增加至483,489，不能把跨长度改善全部归因于时间信息。
### 9.3 Memory

194679使用0.08/0.40秒快慢EMA，4×4 coarse cells中4个细化，28 tokens/摄像头、共56；194716保留10个独立bin，读出560 tokens。无早停194822沿用同一结构。更大模型或更多时间token没有自动带来更好的OOD；现有证据只说明这些具体实现及训练协议落后，不能证明attention或memory一般性无效。
### 9.4 VAE与patch4

195548将最早历史bin前补3次，10个真实bin组成13帧因果输入，冻结LeanVAE输出4个latent时间片；单帧组独立编码当前帧再重复4槽。原始latent空间16×16，尚未进入DiT。
195580/195609复用完全相同的历史latent缓存，所有分支输出[B,4,2,768,4,4]并用相同初始化的预测头：raw_patches先做可逆4×4重排（每patch256标量），再重复通道并除sqrt(3)无损扩至768；trained/random分支为冻结Conv2d(16→768,k4,s4)。这里128px输入每时间片每摄像头只有16 tokens，不能当作生产256px下64 tokens的完整验证。
静态投影来自179463的80k；动态投影来自182549的80k、固定0.06 m/s传送带训练。它们只含event_input投影与bias，不含camera embedding、RoPE或DiT上下文。动态投影审计秩256，满列秩；单靠patch数量下降不能断言速度信息被不可逆丢失，BF16数值效应与读出难度需另论。
Raw/readout重新组织空间后也明显优于195548原latent头，说明预测头与特征组织本身就是变量。随机投影接近训练投影进一步限制了结论：不能把probe成绩全部归因于EWM学到了动力学。
### 9.5 重复记录与证据强度

194851的feature_diff与194586的history、194865的feature_diff与194643的dense10在现存summary中数值完全一致；195609的raw/random也与195580一致。保留这些行是为了完整追踪配对实验，不将它们作为新增独立重复的统计证据。三种子标准差不能代替场景级配对置信区间，尤其是投影方法之间很小的差值。

## 10. 建议与尚未验证的问题

1. 保留10-bin像素差分CNN作为高速运动读出基线；保留raw patch与冻结patch4作为latent读出基线，不以单一宏平均选掉高速更好的方法。
2. 后续闭环实验优先比较原EWM与接入历史特征的EWM，训练数据与速度分布相同；同时测未来位移/速度和抓取成功率，确认可读出的速度是否真正被使用。
3. 若定位外推瓶颈，增加GT速度条件对照，区分速度估计与生成/控制利用。当前probe只覆盖接近物体前，未验证接触、遮挡、全轨迹、真机或其他物体。
4. 这些试验多次复用了同一OOD测试集做探索；正式论文定稿前应以新的保留场景/速度检验最终方案，避免将反复探索后的最优当作完全未见测试。
5. 当前报告不包含闭环抓取评测、0.09 oracle、推理延迟或历史token控制训练，它们回答不同问题；本次未新增实验。
