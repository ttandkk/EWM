独立账号部署准备清单

状态：已导出旧环境依赖；尚未在新账号安装验证。不要直接把 requirements.snapshot.txt 当成已验证的一键安装 lockfile。

1. 搬运内容
- OpenWAM 当前源码和本地改动，包括未跟踪的 EWM 模块、配置、脚本、测试、文档。
- Event-DataCollection 当前源码、未跟踪文件、资产、兼容代码以及固定的第三方版本。
- 根目录 scripts/、docs/ 和必要 assets/。
- datasets/ 完整已导出数据，保留 meta/、normalization、时间契约、完成标记和视频/event payload。
- pretrained/：至少 DINOv3、T5-small、LeanVAE；可选 Wan2.2。
- 选定 policy checkpoint 与对应 config.yaml、normalization 配置和关键评测指标。
- 本目录依赖快照。
无需搬运旧 Python 环境、Isaac 安装目录、缓存和完整历史 outputs/。

3. 独立环境
OpenWAM：Python 3.10，Torch 2.7.1+cu128，Torchvision 0.22.1+cu128，Transformers 5.17.0，Diffusers 0.40.0，NumPy 2.2.6，TorchCodec 0.5。
LeRobot：Python 3.12，Torch 2.7.1+cpu，Torchvision 0.22.1+cpu，NumPy 2.2.6，源码 commit 7e241bd630a3719a56157a497ce5d08f244784f1。
Isaac：Python 3.12，Isaac Sim 6.0.1.0，Torch 2.11.0+cu128，Torchvision 0.26.0+cu128，NumPy 2.3.1，Transformers 4.57.6。
IsaacLab：使用 runtime commit ffff603eafc6b74264a5261cc0183d6a65390d78（v3.0.0-beta2.patch1，package 6.1.14）。不要用采集仓库内的 legacy IsaacLab 替代它。
FFmpeg：单独恢复 FFmpeg 7 原生共享库，导出清单为 ffmpeg.conda-packages.json；TorchCodec 路径需要 LD_LIBRARY_PATH。也可先用已支持的 PyAV 后端验证数据读取。

4. 安装顺序
先安装各自 Python 和固定 Torch/Torchvision，再补齐同环境普通依赖。
OpenWAM 在新目录执行 pip install -e OpenWAM，并检查 import openwam 的路径属于新账号。
LeRobot 在新目录安装固定版本源码，供采集 writer 和转换使用。
Isaac Sim 使用 NVIDIA 官方索引安装固定版本；官方基础形式为：
python3.12 -m venv "$NEW_PROJECT_ROOT/isaacsim601/env"
"$NEW_PROJECT_ROOT/isaacsim601/env/bin/python" -m pip install 'isaacsim[all,extscache]==6.0.1.0' --extra-index-url https://pypi.nvidia.com
随后安装固定 runtime IsaacLab 源码包、agx_teleop 和 dvs_gen，重建所有 editable 绑定。

当前 Isaac 是经过任务验证的精简组合，不是所有 IsaacLab extras 都安装。
已知 EVIS 元数据要求 numpy<2，但原有实测组合是 numpy==2.3.1；不要让安装事件插件的依赖解析把 NumPy 降级。普通依赖先恢复到已验证版本，然后对这些固定源码包按原验证方式安装（必要时 --no-deps）。
快照记录了所有已安装包，包括 Conda 提供的包及框架内部包，需要区分包来源、索引和安装顺序；直接对三个快照同时 pip install 不等于恢复原环境。

5. 路径和启动脚本
修改 root scripts/ 和 OpenWAM/scripts 的旧 project_root、Slurm stdout/stderr、cache/config 路径；Slurm 头中的路径也要单独改。
配置 EWM_DATASET_DIR、EWM_DINO_PATH、EWM_T5_PATH、EWM_VAE_PATH。
采集 writer_python 指向新账号 envs/lerobot/bin/python。
旧路径不得保留在部署入口或 editable 安装中；editable.json 中的旧路径仅用于记录源环境绑定，需要在新账号重新安装。

6. 验收
CPU：模块导入路径、固定版本、一个真实训练窗口、normalization 和 checkpoint 加载。
GPU：几步双摄像头 RGB/event 仿真、一条成功采集并验证写入、一次短训练、一次短闭环评估。
全部通过后再启动正式训练。
